# Upgrade to 1.3

## Dependencies

* Support for `friendsofsymfony/http-cache` 2.x is removed. Upgrade to `friendsofsymfony/http-cache` 3.x.
  The 2.x branch does not receive updates since version 2.16.2 (August 2024).
* Support for `symfony/options-resolver` 4.4 and 5.4 is removed. Use version 6.4 or higher.
